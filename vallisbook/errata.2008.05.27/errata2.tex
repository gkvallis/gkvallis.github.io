\noindent 


The following errata and comments apply to the \emph{second printing} of the book, available from October 2007. (The second printing says `Reprinted 2007' on the copyright page.) If you have the first printing of the book, please see the corresponding errata sheet. Errors that occur in both printings are (or should be) listed in both errata sheets. If you find other errors, or if you think something is poorly explained, please contact the author at `gkv-at-princeton-dot-edu'. 

\begin{enumerate}

\item Page 21, first line of last paragraph. $\bppp h t _p$ should be $\bppp hT_p$.

\item Page 24, \eq (F.2). Second term in left equation should be plus, not minus. See \eq (1.93).

\item Page 27, expression for $Q[\rho]$ on line 3. The second term on the right-hand side should be $+ (\ppp \rho S)_{\eta,p}$ and not $-(\ppp \rho S)_{\rho,p}$.

\item Page 34, line before (1.148). Should be $\alpha  = (\ppp G p)_{T,S}$ and not
$\alpha  = (\ppp G p)_{T,p}$.

\item Page 70, expression following (2.98). Should be minus sign in front of $\cp/(T 
\ro\beta_T)$. [Note the use of the equation of state (1.59).] 

\item Page 74, \eq (2.122). For notational consistency, $\rho'$ should be $\delta \rho$, and similarly in the sentence immediately following. 

\item Pages 81--82, Eqs. (2.167) and (2.174). On right-hand sides $-b$ should be $+b$ and, for more clarity, $\del \phi$ should be $\del_z\phi$ (it is a horizontal derivative).

\item Page 130, \eq (3.33). Extraneous minus sign on rhs.

\item Page 136--137, section 3.6.1. It should probably be stated explicitly that we are considering the $f=0$ case, especially as (3.68) only follows from (3.8) if $f=0$. The rotating case follows on page 138. 

\item Page 147, line before (3.134). In fact, the condition that is imposed is that the \emph{derivative} of streamfunction (i.e., the velocity) goes to zero, not streamfunction itself. 

\item \label{informal} Page 258. This explanation (the informal mechanism) is a little brief and may be hard to follow, and (6.48) is not transparent without more algebra. A clearer version may be provided eventually. 

\item Page 237--238 on phase speed. Some sources define the `phase velocity' to be given by $\cb_p \equiv \omega \kbi / K^2$, where $\kbi$ is the wavevector. The components of the phase velocity are then given by $c^x_p = \omega k^x/K^2$, etc. Defined this way, the phase velocity is a true velocity. However, its components do \emph{not} represent the speed at which wave crests travel along the coordinate axes. This definition is not common, but be aware of it. Also, at the bottom on page 240, the explanation of group velocity is rather terse, and note that ${\omega'} = \omega(k+k') - \omega(k)$.

\item Page 343, \eq (8.17). $\wtilde u(\kbi)$ should be $\wtilde u(\kbi,t)$. {}

\item Page 456, \eq. (11.3). The signs on the right-hand sides of both equations such be flipped in order to be consistent with figure (11.3) and \eq (11.68). Note, though, that there is no a priori correct definition of the sign of a streamfunction. 


\item Page 536--537. The appendix discusses the computation of the EP fluxes in log-pressure coordinates. However, the computations were actually carried out in pressure coordinates, with the scaling as indicated at the bottom of page 537, and then the results transformed to log-pressure coordinates for plotting purposes only. 

\end{enumerate}
