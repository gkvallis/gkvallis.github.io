Walsh Lecture Notes (Source Code) by G. K. Vallis


This is the zip file of the latex source code. After unzipping, the main file is called GFD14.tex. You should 'pdflatex' this file to create the final PDF file. The lectures themselves are in lectures-atmos.tex and lecture-ocean.tex. The figures are in a directory called figures, amazingly enough.

Note that these notes contain about twice as much material as was actually presented in the lectures.

Let me know if you have any problems.
